# JobPortal

## Run during development

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal (usually `http://localhost:5173`).

## Open without a server

Run `npm run build`, then open `dist/index.html`. The build uses relative asset
paths and a regular browser script, so it also works when opened directly from
the file system.

> Do not open the project-root `index.html` by double-clicking it. It is Vite's
> development entry point and needs Vite to transform React/JSX and resolve its
> package imports.
